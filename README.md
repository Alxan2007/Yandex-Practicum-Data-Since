# Yandex-Practicum-Data-Since

## Спринт 1. SQL, Извлечение данных.

### ТИПЫ ДАННЫХ:

#### ЧИСЛОВЫЕ ТИПЫ:
- **INTEGER** — целые числа
- **NUMERIC** — можно указать точность целого числа и после точки
- **REAL (FLOAT4)** — числа с плавающей точкой (4 байта)
- **DOUBLE PRECISION** — числа с плавающей точкой (8 байт)

#### ВРЕМЕННЫЕ ТИПЫ ДАННЫХ:
- **TIMESTAMP** — дата и время (год-месяц-день и часы:минуты:секунды)
- **TIME** — время (часы:минуты:секунды)
- **DATE** — дата (используют для даты рождения, регистрации и т.д.)

### ФУНКЦИИ:

#### ОКРУГЛЕНИЯ ЧИСЛОВЫХ ДАННЫХ:
- **ROUND** — округляет до указанного количества знаков после запятой
- **CEIL** или **CEILING** — округляет вверх
- **FLOOR** — округляет вниз

## Синтаксис оператора LIKE

Оператор `LIKE` используется для поиска строк по шаблону с использованием символов-шаблонов:
- `%` — любая последовательность символов (включая пустую)
- `_` — ровно один любой символ

---

## Примеры использования

| Выражение | Что попадёт | Пример кода | Результат |
|-----------|-------------|-------------|-----------|
| `'text%'` | Значения, которые **начинаются** с `text` | `WHERE quotes LIKE 'кот%'` | `'кот просил еды'`<br>`'котелок не варит'` |
| `'%text'` | Значения, которые **заканчиваются** на `text` | `WHERE quotes LIKE '%кот'` | `'куда пропал кот'`<br>`'двойной апперкот'` |
| `'%text%'` | Значения, в которых `text` занимает **любую позицию** | `WHERE quotes LIKE '%кот%'` | `'кота зовут василий'`<br>`'они танцевали котильон'` |
| `'te%xt'` | Значения, которые **начинаются** на `te` и **заканчиваются** на `xt` | `WHERE quotes LIKE 'ко%т'` | `'кот играет'`<br>`'консультант'` |


```sql
-- Примеры числовых типов
CREATE TABLE products (
    id INTEGER,                      -- целое число
    price NUMERIC(10,2),             -- 10 цифр, 2 после запятой
    rating REAL,                     -- 4.5
    revenue DOUBLE PRECISION         -- 12345.6789
);

-- Примеры округления
SELECT 
    price,
    ROUND(price, 2) AS rounded,      -- 99.99 → 100.00
    CEIL(price) AS ceil_up,           -- 99.01 → 100
    FLOOR(price) AS floor_down        -- 99.99 → 99
FROM products;

-- Практический пример: средняя цена с округлением
SELECT 
    ROUND(AVG(price), 2) AS avg_price
FROM products;

-- Практические примеры


-- Поиск пользователей с именем, начинающимся на 'A'
SELECT * FROM users WHERE name LIKE 'A%';

-- Поиск email в домене @gmail.com
SELECT * FROM users WHERE email LIKE '%@gmail.com';

-- Поиск товаров, содержащих слово 'phone' в названии
SELECT * FROM products WHERE name LIKE '%phone%';

-- Поиск пользователей с именем из 5 букв
SELECT * FROM users WHERE name LIKE '_____';
